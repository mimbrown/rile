# Operator dictionary

`operators.txt` is converted from SILE's `packages/math/mathml-entities.lua`
by `scripts/import-sile-math.py`. SILE's file was itself extracted from the
W3C's `unicode.xml` (https://github.com/w3c/xml-entities), whose notice
follows. rile's copy is modified: reduced to each character's atom type,
TeX-like name and operator forms, in a tab-separated format of its own
(git history has the dates).
